# Pulseboard — Analytics Workspace

A responsive React + TypeScript + Vite portfolio dashboard. The refreshed design uses a forest-green sidebar, warm neutral canvas, lime accents, and teal/coral visualisations.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Build for deployment

```powershell
npm.cmd run build
```

## Features

- 7-, 30-, and 90-day reporting ranges with matching summary metrics
- Interactive visitor, session, and conversion trend chart
- Optional previous-period comparison line and KPI comparison badges
- Selectable traffic channels that filter page and campaign data
- Searchable, sortable page performance table with CSV export
- Device mix and conversion funnel views
- Campaign monitor with status, spend, conversions, and sample ROAS
- Light/dark theme toggle
- Activity inbox and workspace account menu
- Add, persist, and delete workspace annotations using localStorage
- Responsive layout for desktop, tablet, and mobile
- Keyboard-focus states and reduced-motion support

All metrics and campaign results are illustrative and are not connected to Google Analytics or any live analytics provider. Workspace annotations are stored in the current browser only.
